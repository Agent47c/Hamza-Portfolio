## 💻 Local Development

### 1. Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### 2. Installation
```bash
git clone https://github.com/Agent47c/Hamza-Portfolio.git
cd Hamza-Portfolio
npm install
```

### 3. Run Dev Server
```bash
npm run dev
```
Open `http://localhost:5173` in your browser.

### 4. Build for Production
```bash
npm run build
```
The production bundle will be generated in `dist/`.
